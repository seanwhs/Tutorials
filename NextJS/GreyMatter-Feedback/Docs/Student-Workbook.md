# 6. Writing Better Comments

## 6.1 Weak and Strong Examples

| Weak Comment | Why It Is Weak | Stronger Comment |
|---|---|---|
| `Bad session.` | Does not explain what was wrong | `The session moved too quickly during the generics examples. A slower walkthrough would help.` |
| `I liked it.` | Does not explain what worked | `The live coding examples helped me understand how interfaces are used in real projects.` |
| `Too hard.` | Does not identify the difficult topic | `The explanation of union types was difficult because there were few examples before the exercise.` |
| `More practice.` | Not specific enough | `Add one guided exercise after the explanation of type annotations before asking students to work independently.` |
| `Teacher was good.` | Too broad | `The instructor explained the first example clearly and checked understanding before moving to the exercise.` |

# 8. Respectful Feedback Checklist

Before submitting written feedback, check each item.

```text
[ ] My feedback focuses on the learning experience.

[ ] I explained what worked or what did not work.

[ ] I used respectful language.

[ ] I avoided personal attacks.

[ ] I suggested an improvement where possible.

[ ] I avoided private or sensitive personal information.

[ ] I reviewed my spelling and meaning.

[ ] My feedback would help an instructor improve a future session.
```

---

# 9. Privacy Checklist

Do not include the following in feedback comments:

```text
[ ] Passwords
[ ] Home address
[ ] Phone number
[ ] Financial information
[ ] Medical information
[ ] Private details about another student
[ ] Confidential employer or customer information
[ ] Sensitive personal data unrelated to the session
```

If you need to report a serious issue involving safety, harassment, discrimination, or misconduct, use your organization’s official reporting process instead of a general anonymous feedback form.

# 11. If Something Goes Wrong

| Problem | What to Do |
|---|---|
| QR code does not scan | Use the typed web address or ask facilitator for link |
| Wrong session title appears | Do not submit; ask for correct QR code |
| Form says feedback is closed | Ask facilitator whether feedback period ended |
| Required question error appears | Answer the highlighted question |
| Internet connection fails | Reconnect; your draft may be saved |
| Browser refreshes | Reopen form in same browser; draft may restore |
| Submission fails | Keep your answers, reconnect, and try again |
